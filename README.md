#  FastAPI Project

##  Project Overview

This project demonstrates how to build RESTful APIs using **FastAPI**, a modern Python web framework designed for developing high-performance APIs.
FastAPI provides automatic interactive API documentation, request and response validation, and support for asynchronous programming. It is useful for building backend services and deploying machine learning models through API endpoints.

##  Technologies Used

- Python
- FastAPI
- Uvicorn
- Pydantic
- REST API
- JSON
